# E-BLOCK Short Sales Teaser

38-second 9:16 local sales cut built from real E-BLOCK demo footage. The app is never covered by persistent text overlays: copy is limited to the opening hook and closing slate, while footage is connected with brief motion-only transitions.

Render locally (no Docker):

```powershell
npm install
npx hyperframes render -o ..\videos\eblock-short-sales-teaser-hyperframes-1080x1920.mp4 -q standard -w 1 --low-memory-mode
```

The narration is `es-CO-GonzaloNeural` generated with the local `edge-tts` command. Treat the output as a local review asset; use an owned, licensed speech service before commercial distribution.
